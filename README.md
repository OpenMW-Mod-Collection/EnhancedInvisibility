# Enhanced Invisibility (OpenMW)

Using invisibility now changes the way you view the world. Not only you become transparent, but you also start seeing through an ethereal lens that warps and twists the environment around you.

_For an MWSE alternative, check out [MM - Enhanced Invisibility](https://www.nexusmods.com/morrowind/mods/47565) by Vtasek, OperatorJack and Kurpulio._

Enhances Invisibility effect with new shader and VFX.

Modernized and heavily optimized version of [openmw-enhanced-invisibility](https://gitlab.com/fallchildren/openmw-enhanced-invisibility) by fallchildren, wazabear and Epoch.

## Compatibility

Safe to install or update mid-playthrough.  
Before deleting, make sure you're not under Invisibility effect.

Might raise issues with mods that use invisibility in a weird way, but that's rare and can also be easily patched. Currently patched for:

- [Silt Striders](https://www.nexusmods.com/morrowind/mods/42267)
- [Gondoliers](https://www.nexusmods.com/morrowind/mods/43291)
- [Boats](https://www.nexusmods.com/morrowind/mods/42270)

## Requirements

- OpenMW 0.52 Nightly or newer
- [MM - Enhanced Invisibility](https://www.nexusmods.com/morrowind/mods/47565)
